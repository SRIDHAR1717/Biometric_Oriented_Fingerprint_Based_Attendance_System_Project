Fingerprint-Based Attendance System with Deep Learning Classification and Biometric Accuracy Evaluation

This project presents an end-to-end biometric attendance system that performs fingerprint authentication using minutiae extraction and classification using deep learning models including CNN, ResNet, and EfficientNet. An ensemble learning approach improves classification accuracy and reduces biometric errors.

The system evaluates performance using False Acceptance Rate (FAR), False Rejection Rate (FRR), and Equal Error Rate (EER), ensuring reliability and security. A Flask-based backend handles fingerprint registration, matching, classification, and attendance logging with timestamped Excel storage.

The solution provides a scalable and secure alternative to traditional attendance systems and demonstrates practical deployment of biometric machine learning models.

Technologies Used: Python, TensorFlow, Keras, Scikit-learn, OpenCV, Flask, Pandas, HTML, CSS
